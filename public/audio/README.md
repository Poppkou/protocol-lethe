# Озвучка

Пока здесь пусто, игра говорит синтезом речи браузера. Когда запишете настоящие голоса:

1. Положите файлы в `public/audio/voice/` в формате **mp3**. Имя файла — это ключ реплики:
   - голосовые Сони: `m1.mp3` … `m7.mp3` (ключи из `voices` в `src/content/script.ru.json`);
   - реплики Системы: по ключу из `lines`, например `final.f1.mp3`, `quiet.good.mp3`.
2. В `src/content/script.ru.json` поставьте `"audio": { "voiceFiles": true }`.

Если какого-то файла нет, вместо него звучит синтез речи.

Советы по записи:
- Голос Системы — ровный, без дыхания: вырежьте все вдохи при монтаже.
- Соню записывайте бинауральным микрофоном или хотя бы близко и сухо: эхо бассейна добавит игра.
- Громкость: пики не выше −1 dBTP, речь около −20 LUFS.
