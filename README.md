# Протокол: Лета

Мобильный психологический хоррор на 20 минут. Приложение-«клинер памяти» стирает воспоминания о Соне, а игрок решает, оставить ли последнее её голосовое сообщение.

Из одного кода собираются две версии:

| | Версия 1 — для телефона | Версия 2 — полная, на ПК |
|---|---|---|
| Что это | Один HTML-файл, `dist-phone/` | Проект Vite + Capacitor → приложение Android/iOS |
| Как запустить | Открыть ссылку | `npm run dev`, Android Studio, Xcode |
| Как править | «Режим автора» в самой игре | Любой редактор кода (VS Code) |
| Микрофон, камера, наклон | Да на своём HTTPS-сайте, нет в артефакте Claude | Да |
| Вибрация | Android-браузер | Android и iPhone |
| Настоящие уведомления, яркость, фото в галерею | Нет (есть замены) | Да |

## Версия 1: играть и править на телефоне

### Запуск
- **Артефакт Claude** — открывается сразу по ссылке. Но артефакт запрещает странице микрофон, камеру и датчики наклона, поэтому игра переходит на замены: «не дыши» превращается в «не касайся экрана», наклон — в движение пальцем, камера — в отражение в чёрном экране.
- **Свой HTTPS-сайт** — все датчики работают. Самый простой путь — GitHub Pages: залейте проект в репозиторий, в настройках включите *Settings → Pages → Source: GitHub Actions*. Workflow `.github/workflows/pages.yml` сам соберёт и опубликует игру при каждом изменении в `main`. Можно и вручную: залить `index.html` и `script.ru.json` из `dist-phone/` на любой хостинг с HTTPS.

### Режим автора
Откройте игру с `#dev` в конце адреса или **пять раз быстро коснитесь левого верхнего угла**. Внизу слева появится кнопка ✎.

- **Сцены** — переход к любой сцене и скорость ×1 / ×3 / ×10.
- **Тексты** — все реплики, голосовые, пункты соглашения и тайминги с поиском. Правки сразу работают в игре.
  - *Сохранить* — в артефакте Claude публикует новую версию `script.ru.json`, в браузере хранит черновик на этом устройстве.
  - *Экспорт JSON* — скачать `script.ru.json` и перенести на ПК в `src/content/`.
- **Датчики** — живые значения микрофона, наклона и вибрации, чтобы проверить телефон.

В консоли браузера с `#dev` доступен `window.lethe` (режиссёр сцен, состояние, звук).

## Версия 2: полная версия на ПК

### Что установить
- [Node.js 22+](https://nodejs.org) и редактор, например [VS Code](https://code.visualstudio.com).
- Для Android — [Android Studio](https://developer.android.com/studio) (в нём есть SDK и эмулятор).
- Для iPhone — Mac с Xcode и Apple ID.

### Первый запуск
```bash
npm install
npm run dev          # игра в браузере ПК: http://localhost:5173/#dev
npm run dev:https    # то же по HTTPS — откройте на телефоне в той же Wi-Fi-сети
```
Телефонный браузер даёт микрофон, камеру и датчики только по HTTPS, поэтому для теста на телефоне нужен `dev:https`. Адрес вида `https://192.168.x.x:5173` покажет Vite. Предупреждение о сертификате нужно принять, сертификат самоподписанный.

### Android-приложение
```bash
npm run android:init   # один раз: создаёт android/ и добавляет разрешения
npm run android        # собирает игру и открывает Android Studio
```
В Android Studio подключите телефон с включённой отладкой по USB и нажмите ▶ Run. Готовый APK: *Build → Build App Bundle(s) / APK(s) → Build APK(s)*.

### iPhone-приложение (только на Mac)
```bash
npm run ios:init
npm run ios            # открывает Xcode
```
В Xcode выберите свою команду в *Signing & Capabilities* и запустите на телефоне.

После любых правок кода повторите `npm run android` или `npm run ios`. Это пересоберёт веб-часть и скопирует её в приложение.

### Версия для телефона из этого же проекта
```bash
npm run build:phone    # → dist-phone/lethe.html, index.html, script.ru.json
```

## Как устроен код

```
src/
  content/script.ru.json   все тексты, голосовые, тайминги — правьте здесь
  main.js                  сборка игры: контекст сцен, реплики, уход из игры
  app.js / phone.js        входы для полной версии и для одного HTML-файла
  core/                    режиссёр сцен, состояние и сохранение, подстановки текста
  scenes/                  сцены по порядку тайминга (intro → early → mid → climax → final)
  audio/audio.js           весь звук: дождь, гул, светофор, сердце, шёпот, тон Шепарда, крик…
  audio/tts.js             синтез речи; записанная озвучка — public/audio/voice
  sensors/                 микрофон (дыхание, запись фразы), наклон и «экраном вниз», камера
  fx/                      вибрации, чернила и глитч, запотевшее стекло, трещины, фигура, фото, рисунок
  platform/                Capacitor-плагины (в версии для телефона — заглушка)
  ui/                      каркас экрана и «Режим автора»
scripts/
  build-phone.mjs          сборка версии в одном файле
  patch-native.mjs         разрешения для Android/iOS
```

**Сцена** — объект в `src/scenes/*.js`:
```js
export const myScene = {
  id: 'my',                       // уникальный id
  title: 'Моя сцена',             // название в «Режиме автора»
  env: { mode: 'void', ticker: true },  // фон: system | void | red | white, звук светофора, батарея и т. д.
  async run(ctx) {
    await ctx.say('ключ.реплики');      // печатает и озвучивает строку из script.ru.json
    await ctx.wait(2000);               // пауза (учитывает ускорение ×3/×10)
    ctx.haptics.lubdub();               // удар сердца
    ctx.audio.whisper();                // шёпот за спиной
  },
};
```
Чтобы сцена появилась в игре, добавьте её в `src/scenes/index.js`.

В текстах `{name}` подставляет имя игрока, а `{|а}` — окончание по выбранному роду: `сказал{|а}`, `решил{ся|ась}`.

## Что проверено, а что нет
- Обе сборки собираются. Бот прошёл все три концовки в Chromium с поддельными микрофоном и камерой, ошибок нет.
- `cap add android` и `cap add ios` создают проекты, скрипт разрешений их правит.
- Сборку APK в Android Studio и запуск в Xcode здесь проверить было нельзя (нет Android SDK и Mac). Также не проверены вибрация, гироскоп и звук на реальных телефонах.

## Приватность
- Запись голоса «Я хочу забыть» живёт только в памяти до конца сеанса. Ответ в секретной концовке не сохраняется вовсе.
- Кадры камеры не сохраняются. Поток выключается через полсекунды.
- Галерея — только добавление одной фотографии в концовке «Лета». Чужие фото игра не читает.
- Ничего не отправляется в интернет.
